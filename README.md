# Procurement Dashboard — Power BI

> An interactive procurement dashboard built with Power BI and Excel to analyze procurement spending by supplier, department, and product.

---

## Overview

This project demonstrates the development of a procurement dashboard using sample procurement data.

The dashboard provides an interactive overview of procurement spending and allows users to analyze purchasing data from different perspectives.

### Analysis Areas

- Supplier
- Department
- Product

## Data Preparation

The procurement dataset was prepared and transformed using Power Query before being used to create the dashboard.

The data preparation process included:

- Checking data types
- Removing unnecessary spaces from text data
- Creating a calculated column for total spending
- Preparing data for visualization and analysis
